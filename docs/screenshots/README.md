# TraceTest Product Screenshots & Screen Index

This directory contains pristine desktop and laptop screenshots captured from the live, running TraceTest AI platform (`http://127.0.0.1:8001`) with real enterprise data (Dayforce Enterprise HCM and EchoBox).

All captures use standard enterprise viewports:
- **Primary Resolution:** `1920 × 1080` (Full HD Desktop)
- **Secondary Resolution:** `1440 × 900` (Modern Laptop)

Mobile and tablet layouts are excluded in accordance with the enterprise evaluation specification.
